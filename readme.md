- `vscode`: `flatpak`, microsoft version.
- `kdenlive`: `pacman`.
- `spectacle`: `pacman`.
- `parsec`: AUR.
- `brave`: AUR.
- `yay`: *lol*...

Recomendadisimo `yay`. Esta escrito en `go`.

Volviendo al bluetooth, realmente no he terminado de comprobar si

proximo log estare inmortalizando que tal.

En la medida que siga instalando mis apps, seguire llenando con logs
hasta lograr mi guia definitiva para arrancar linux desde cero. *This
is how the show begins*.
